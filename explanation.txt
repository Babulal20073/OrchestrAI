///------ FireBase auth handling --------
// Firebase Authentication: Handles user identity, signup/login, credentials,
// and issues a signed Firebase ID token (JWT) to the client.

// Signup: Client sends credentials to Firebase → Firebase creates the user
// and returns an ID token containing the user's Firebase UID.

// Login: Client sends credentials to Firebase → Firebase verifies them
// and returns an ID token (JWT) to the authenticated client.

// Frontend → Backend: Client sends the Firebase ID token in the
// Authorization: Bearer <token> header when calling protected APIs.

// Backend verification: Firebase Admin's verifyIdToken() verifies the
// token's signature/claims and gives the backend the trusted Firebase UID.

// MongoDB: Backend uses the verified Firebase UID to find/create the
// corresponding application user using { firebaseUid: decodedToken.uid }.

// firebaseUid: Acts as the link between Firebase's authenticated user
// and the corresponding MongoDB user document.

// Password: Firebase handles authentication credentials; your MongoDB
// user document does not need to store the user's password.

// Logout: Signs the user out of Firebase/client authentication;
// it does not mean deleting the MongoDB user.

// Core flow:
// React → Firebase Auth → ID Token → Express → verifyIdToken()
// → verified UID → MongoDB User
